# ZephyCubeRecipe v1.0.1

Custom crafting recipes for Minecraft Bedrock Edition.

> [!NOTE]
> This add-on is built for, and tuned specifically for, [WhitemaneSMP](https://whitemane.fun/). It is a data-only pack with no modules; to turn it off, remove the pack from the world.

## Install

Download `ZephyCubeRecipe-v1.0.1-BP.mcaddon` (behavior pack; this add-on has no resource pack) or `ZephyCubeRecipe-v1.0.1.mcpack` from the Releases page and open it. Or install by hand: copy the `ZephyCubeRecipe` folder into your world's `behavior_packs` folder and add its `uuid` and `version` (from `manifest.json`) to the world's `world_behavior_packs.json`.

## Features
| Recipe | Pattern |
| --- | --- |
| Enchanted golden apple (`zc:enchanted_golden_apple`) | 8 gold blocks around 1 golden apple, crafting table, always unlocked |
