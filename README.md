# ZephyCubeRecipe v1.0.0

ZephyCube Recipe for Minecraft Bedrock Edition. Custom crafting recipes.

## Install

Download `ZephyCubeRecipe-v1.0.0.mcpack` from the Releases page and open it, or copy the `ZephyCubeRecipe` folder into your world's `behavior_packs` folder and add its `uuid` and `version` (from `manifest.json`) to the world's `world_behavior_packs.json`.
